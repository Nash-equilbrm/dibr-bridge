# IMPORTANT — opencv-contrib-python vs opencv-python conflict:
# requirements.txt installs plain `opencv-python`. Fast-FoundationStereo's own
# requirements.txt lists `opencv-contrib-python`, which provides the same
# `cv2` module (a strict superset of opencv-python) — the two packages must
# NOT both be installed in the same venv (they conflict at the `cv2` import).
# Before installing this file, run:
#   pip uninstall opencv-python -y
# `opencv-contrib-python` below covers everything the sgbm backend needs too,
# so this is safe — it doesn't affect StereoDepthComputer's behavior.
#
# Also requires: the Fast-FoundationStereo repo (fork) cloned as a SIBLING
# repo next to this one, i.e. ../Fast-FoundationStereo relative to this file
# (override with the FFS_REPO_PATH env var) — see README.md's "Alternative
# stereo backend" section.
#   git clone https://github.com/Nash-equilbrm/Fast-FoundationStereo.git ../Fast-FoundationStereo
#

# Google-Drive-gated under the NVIDIA Open Model Agreement, no stable direct
